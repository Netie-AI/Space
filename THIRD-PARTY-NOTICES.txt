NETIE SPACE - THIRD-PARTY NOTICES
=================================

Netie Space (Netie PDF, Netie Image, Netie Video) ships or calls the components below.
Licences for NuGet packages are the ones each package declares in its own metadata
(the .nuspec of the exact version in NetieSpace.csproj). Nothing here changes the licence
of any component.

Netie Space never ships PyMuPDF, pymupdf4llm, Ghostscript or OnlyOffice. The package
build refuses to finish if any of them is present (scripts/check-tool-engines.ps1).


1. FFmpeg - GNU General Public License v3 (GPLv3)
-------------------------------------------------
Files: tools\ffmpeg\ffmpeg.exe and tools\ffmpeg\ffprobe.exe
Build: FFmpeg 8.1.2, "release-essentials" build by gyan.dev, configured with --enable-gpl
and --enable-version3, so the whole build is licensed under the GPL version 3.

FFmpeg is run as a separate process (command line); it is not linked into Netie Space.
It is a separate work and is distributed here in unmodified binary form.

Corresponding source and build information:
  https://ffmpeg.org/                      (FFmpeg source and releases)
  https://www.gyan.dev/ffmpeg/builds/      (the build shipped here and its configuration)

The text of the GPL v3 is at https://www.gnu.org/licenses/gpl-3.0.txt . You may replace the
bundled ffmpeg.exe and ffprobe.exe with your own build of FFmpeg in the same folder.

4. Runtime
----------
The self-contained build includes the .NET 8 runtime and the Windows Desktop runtime
(MIT, Microsoft). Tesseract OCR, when used, is a separate system installation (Apache-2.0)
and is not part of the package.
