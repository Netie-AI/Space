Netie Space — AirGPT connector

This bundle registers Netie Space as the Space-key / Open-in-Space handoff for AirGPT.

  1. Install Netie Space (Install.bat or NetieSpace-Setup.exe).
  2. Copy airgpt-plugin/manifest.json into AirGPT’s connectors folder (or run register-airgpt-plugin.ps1).
  3. AirGPT “Open in Space” → NetieSpace.exe --preview "path".

Local dual-brain embeddings stay on the user’s PC under %LOCALAPPDATA%\NetieSpace\.netie-brain (hidden, consent-gated).
