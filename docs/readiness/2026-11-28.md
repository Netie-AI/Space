## Fixes in this branch

1. `FfmpegExportGraph.ScalePad`: `setpts=PTS-STARTPTS` moved before `fps=30`. On FFmpeg 7.1 setpts after fps leaves the frame rate unknown and `xfade` refuses ("inputs needs to be a constant frame rate"), so every timeline export with a wipe failed. Same order works on 7.1 and 9.0. Mirrored in the python test and both pillar1 scripts.
2. `vid-speed`: resample to the source rate after `setpts`. On FFmpeg 7.1, 200% speed kept all 60 frames at an odd rate (4608/95) instead of 30 frames at the source rate.

The 503s come from the local runtime (the login handler has no 503 path); production capacity was not measured. Bigger finding: `crypto.ts` hashes with PBKDF2 at 310,000 iterations. Deployed Workers reject PBKDF2 above 100,000 iterations (NotSupportedError), and local workerd does not enforce that limit, so register and login pass here and would return 500 in production. The worker is not deployed yet (the workers.dev host does not resolve), so this is a pre-deploy blocker, not a live outage.
